# Taller de Skills · Nuevas Tecnologías (CESDE)

Material del curso Nuevas Tecnologías de Programación, proyecto integrador 2026-2.

- **Taller de Skills** (`index.html`): qué es una skill de claude.ai, un kit listo para explorar, instalar y probar (`factura-a-web`), y dos asistentes para construir skills propias: uno para las HU del proyecto (F01 + X01, L01, Q01, G01) y otro para cualquier otra necesidad.
- **Guía por HU** (`guia_hu_skills.html`): criterios de cada historia de usuario y el recorrido para construir una skill por HU.

## Ver el sitio

Publicado con GitHub Pages: https://profejuanjosegallego.github.io/tutorialskillsIA/

## Notas

- Las páginas no necesitan servidor: todo funciona en el navegador. Lo que escribes en los asistentes se guarda solo en tu navegador.
- Las skills se usan en [claude.ai](https://claude.ai) con la ejecución de código encendida (funciona en el plan gratuito).
